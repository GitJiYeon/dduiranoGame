## 📌 프로젝트 소개

**뛰라노 게임**은 크롬 공룡 게임을 모티브로 제작한 Python 기반 2인용 러닝 게임입니다.

두 명의 플레이어가 한 화면에서 동시에 플레이하며,
점프와 웅크리기를 사용해 장애물을 피하고 더 오래 살아남는 것을 목표로 합니다.

기본적인 장애물 회피 모드뿐만 아니라 **아이템전 배틀모드**를 추가하여
단순한 러닝 게임에 경쟁 요소와 재미를 더했습니다.

또한 플레이어가 직접 공룡 캐릭터를 그릴 수 있는 **커스터마이징 기능**을 구현하여,
자신만의 캐릭터로 게임을 플레이할 수 있도록 제작했습니다.

---

## 🎮 주요 기능

### 2인용 배틀 플레이

* 두 명의 플레이어가 동시에 게임 진행
* 플레이어별 이름 입력 가능
* 각자 원하는 공룡 캐릭터 선택 가능

### 기본 배틀모드

* 선인장, 익룡 등 장애물을 피하는 기본 모드
* 장애물에 충돌한 플레이어가 패배
* 더 오래 살아남은 플레이어가 승리

### 아이템전 배틀모드

* 게임 중 아이템 등장
* 아이템을 획득해 플레이에 활용
* 일반 모드보다 더 다양한 변수와 경쟁 요소 제공

### 공룡 커스터마이징

* 픽셀 단위로 공룡 캐릭터 제작
* 직접 만든 공룡 저장 가능
* 저장한 커스텀 공룡을 게임 캐릭터로 선택 가능

### 설정 기능

* BGM 볼륨 조절
* BGM 켜기 / 끄기
* 다크 모드 설정
* 설정값 저장

## 📁 프로젝트 구조

```bash
dduiranoGame/
├── images/                 # 게임 이미지 리소스
├── sounds/                 # BGM 및 효과음
├── main.py                 # 메인 화면
├── game_screen.py          # 기본 게임 화면
├── game_screen_item.py     # 아이템전 게임 화면
├── choice_image.py         # 캐릭터 선택 화면
├── choice_mode.py          # 게임 모드 선택 화면
├── draw_image.py           # 공룡 커스터마이징 화면
├── file_management.py      # 파일 및 설정 관리
├── setting.py              # 설정 화면
├── check_custom_Dino.py    # 커스텀 공룡 확인 화면
└── __init__.py
```

## 🚀 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/GitJiYeon/dduiranoGame.git
```

```bash

```
